Here's where I'll put any bugs or issues I run into, as well as the solutions/fixes, over the course of working on this project.

(FIXED) 1. Error with Node js passing client password as something that isn't a string. I think the issue here is just the way I calling the environment variables, hopefully a quick fix.
It turns out the problem is simply the connection script and the env file being in different directories is the cause of the issues, since the dotenv can't locate the needed environment variables.

The fix was simple, I just had to move the .env file to the root directory, because that's where dotenv looks for that at. Didn't even mean to put .env in the backend folder, whoops.


(FIXED) 2. Error with trying to get the host to be found. Not quite sure how this happened, but apparently my localhost isn't the correct name for what's hosting the server for some reason.
TURNS OUT THE SEMICOLONS IN THE .env WERE THE THINGS CAUSING THE ISSUE. DIDN'T KNOW THAT COULD EVEN CAUSE A PROBLEM?! Dang, I feel really stupid after all this troubleshooting for this issue.
Lesson learned, never use semicolons in an .env file, since it treats everything as a literal part of a value. So DB_PORT=1234; has a port value of 1234;, semicolon included.


(FIXED) 3. Had issues with trying to get index server going. The issue first stemmed from issues importing my pool instance from db.js. The file pathing just seems wrong but I'll fix it.
Solution was exactly the what I said before, file path was just wrong for the import.

(FIXED) 4. There were problems with the way the pool and client instances from db.js were exported, causing the server, index.js, to not be able to load the correct stuff.
The fix took some time, but was simple, all I had to do was export the db.js modules pool and client and check over the import in index.js.


(FIXED) 5. Had some issues with getting importing paths correct for most of the imports. Nothing too complicated, just have to work on my file pathing.
Fix was pretty easy, just had to change the imports to use the appropriate pathing.
